## 리플렉션
- 클래스가 제공하는 다양한 정보(**메타 데이터**)를 **런타임에 동적으로 분석하고 사용**하는 기능
- 메타데이터 종류
	- 클래스
		- e.g. 클래스 이름, 접근 제어자, 부모 클래스, 구현한 인터페이스
	- 필드
		- e.g. 필드 이름, 타입, 접근 제어자
		- **해당 필드 값을 읽거나 수정 가능**
	- 메서드
		- e.g. 메서드 이름, 반환 타입, 매개변수 정보
		- **런타임에 동적으로 메서드 호출 가능**
	- 생성자
		- e.g. 매개변수 타입 및 개수
		- **런타임에 동적으로 객체 생성 가능**
