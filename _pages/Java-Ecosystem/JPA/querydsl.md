## QueryDSL
- 소개
	- JPQL 빌더
	- 장점
		- 문자인 JPQL을 **코드**로 작성해 **컴파일 오류** 발생 가능
		- JPQL과 달리 **파라미터 바인딩을 자동 처리**
- 라이브러리 종류
	- `querydsl-apt`: Querydsl 관련 코드 생성 기능 제공 (Q 클래스 빌드)
	- `querydsl-jpa`: Querydsl 라이브러리
